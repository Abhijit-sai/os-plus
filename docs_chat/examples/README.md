# Unpublished synthetic inquiry example

`new-business.pack.json` is a schema-shaped, fictional example for CH-0 owner review.
It is not a seed, a published tenant knowledge pack or production business content.
Nothing automatically imports or publishes it. CH-1 implements strict Zod validation;
CH-5 accepts only new-business-approved published content.

The example contains no price, booking capability, addresses, phone numbers, links,
model selection or credentials. Its wording is newly written for the synthetic
example. Real language/script, opening hours, services, handoff topics and responses
must come from that new business. Do not use this file as a live reply source.
